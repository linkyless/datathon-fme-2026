# Archivo del evento

Cómo trabajó el equipo durante las 24 h del datathon (sáb 14/11 10:00 → dom 15/11 12:00). Se guarda tal cual se
escribió: aquí están las decisiones de organización, lo que cada uno descubría y los problemas que nos encontramos.
Los nombres de archivos y módulos son los de entonces, en español (la tabla de equivalencias está en el README).

| Archivo | Qué es |
|---|---|
| `status/<persona>.md` | El estado de cada uno (Lester, Leonardo, Alex, Artai): qué hacía, qué descubrió, qué necesitaba de los demás |
| `guides/` | El reparto por roles (Operador, Ranking, Evaluación, Datos y relato), el contrato `Estado` y los dueños de cada archivo |
| `procedures/` | Los pasos de los comandos del equipo: empezar, handoff, eval, check-live, freeze |
| `ROADMAP.md` | El plan por horas y la escalera del recomendador |
| `context.md` | Lo ocurrido antes de empezar a programar (sáb hasta las 13:00) |
| `guide.md` | Guía de instalación y preguntas frecuentes para el equipo |
| `deep_research_prompt.md` | El encargo de investigación; el resultado está en `docs/research.md` |
